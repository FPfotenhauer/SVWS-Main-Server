# USER ROLES and STORIES

## Admin User

Ich bin ein Admin User des Schulträger.
Ich möchte die SVWS-Server-Instanzen verwalten, da ich auf Zeiten mit hoher LAst reagieren möchte.
- neue SVWS-Server aufnehmen
- existierende SVWS-Server aus der Konfiguration löschen
- ich möchte sehen können, welche Schulen auf welchen SVWS-Server instanzen existieren
- ich möchte Schulen neu anlegen können (leeres Schemamit Schulnummer oder Schild-NRW-Datenbank migrieren)
- ich möchte Backups von Schulen erstellen können, auch mehrere auf einmal
- ich möchte Schulen von einem SVWS-Server entfernen können



## Verwaltungs User

Ich bin ein User für die Verwaltung beim Schulträger.
Meine Aufgabe ist es Arbeiten für den Schulträger zu erledigen.
- ich möchte Statistikzahlen von Schulen abrufen können (Schülerzahlen nach Jahrgängen, Klassen, Wohnorten usw.)
- ich möchte eine Entfernungsberechnung Wohnort zur Schule bei bestimmten Schülern durchführen können (Erstattung Schülerticket ab einer bestimten Entfernung Wohnort - Schule)
- ich möchte die Schulpflicht überwachen können

## technische User pädagogisches Netzwerk

Ich bin technische User des Schulträger ggf. so wie der Admin User.
Meine Aufgabe ist es, die pädagogischen Netzwerke für die Schulen zu unterstützen.

- ich möchte ein Identitymanagement für Schüler und Lehrkräfte mit aktuellen Daten der Schulen versorgen
- tägliche Synchronisation mit veränderten Daten in dieses Netzwerk (neue Schüler, Schülerwechsel)
- ich möchte MDM für Schüler und Lehrkräfte verwalten (Ausgabe von Geräten für Schüler und Lehrkräfte)
- ich möchte den Schulen einen Webnotenmanager zuweisen können (externer Webserver zur Notenerfassung)
